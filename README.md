One word describing home Wi-Fi, for make.fun's "One Word for Your Wi-Fi" bounty. The word is "diva": home Wi-Fi works beautifully all day while nothing matters, then throws a tantrum the second an important call starts.

## Run it

```sh
python3 main.py
```

The program writes the word to /output/entry.txt.
